# St. Antony’s Mission Centre — Kangeyam

A responsive GitHub Pages-ready website created from the supplied history document.

## Pages

- `index.html` — Mission Centre home/history page
- `payment-terms.html` — Payment Terms & Conditions
- `styles.css` — shared styling
- `images/` — photographs extracted from the supplied Word document

## Publish

Upload the contents of this folder to a GitHub repository and enable **Settings → Pages → Deploy from a branch → main → / (root)**.

All image paths are relative, so the site works as a static GitHub Pages website.
